# بيت الكهرباء — قالب ووكومرس للأدوات الكهربائية والمنزلية في سوريا

قالب WordPress + WooCommerce مخصص بالكامل، عربي RTL، خفيف جداً (Tailwind + سكربت صغير بدون أي مكتبة)، والطلب عبر واتساب بدون دفع أونلاين، مبني ليتوسع بلا حدود: أي ماركة أو تصنيف (أب ← ابن ← فرعي) تضيفه من لوحة التحكم يظهر تلقائياً في القائمة، صفحات الماركات، صفحات التقاطع `/brand/{ماركة}/{قسم}/`، الفلاتر، السايت ماب، الـ Schema و `llms.txt` — بدون لمس أي سطر كود.

## الهوية البصرية: «ضوء — صالة عرض» (الإصدار 2.0)
المتجر مصمم كصالة عرض هادئة: خلفيات فاتحة، مساحات مريحة، وصورة الجهاز هي البطل.
- **الألوان:** خلفية `#FAF9F6`، منصة الصور `#F1EFEA`، حبر `#15171A` للنصوص والأزرار، أصفر «الضو» `#FFC629` كلون مميز وحيد (تمييز الكلمات، شارة الطاقة الشمسية)، وأخضر واتساب `#1FAF5A` لأزرار الطلب فقط.
- **الخطوط (محلية بالكامل):** Alexandria للعناوين، IBM Plex Sans Arabic للنصوص.
- **بدون سلة ولا دفع أونلاين:** كل منتج فيه زر «اطلب على واتساب» برسالة جاهزة (اسم الجهاز، الموديل، السعر، الرابط) + أزرار أسئلة سريعة («متوفر هلق؟»، «كم التوصيل لعندي؟»، «في تقسيط؟»، «بدي صور من المحل»). روابط السلة والدفع تتحوّل تلقائياً لصفحة المتجر.
- **مفتاح الأمبير:** في الواجهة، تختار اشتراكك (1/2/3/5 أمبير) وبتظهر الأجهزة اللي بتشتغل عليه فوراً.
- **صور تجريبية:** رندرات ثلاثية الأبعاد خالية من حقوق النشر لكل جهاز في `assets/demo/` تُستورد تلقائياً مع البيانات التجريبية — استبدلها بصورك الحقيقية (يفضّل مقصوصة على خلفية `#F1EFEA` أو شفافة، مربعة).

## التشغيل خلال 5 دقائق
1. ارفع مجلد `bayt-kahraba` إلى `wp-content/themes/` (الملفات المبنية `assets/*/dist` موجودة — لا يحتاج الخادم Node).
2. فعّل **WooCommerce** ثم فعّل القالب.
3. الإعدادات ← الروابط الدائمة ← "اسم المقالة" ← حفظ.
4. **بيت الكهرباء ← تهيئة المتجر والبيانات التجريبية** ← "تهيئة المتجر" (أو `wp bk seed`).
5. **بيت الكهرباء ← الإعدادات العامة**: الاسم، الهاتف، **رقم واتساب الطلبات**، العنوان، عنوان ووصف الواجهة.

> ⚠️ نصوص الكفالة ومراكز الصيانة وأرقام الموديلات والأسعار في البيانات التجريبية **قيم نموذجية** — راجعها مع كل وكيل (الحافظ، العربي، هنديكو، رامكو) قبل الإطلاق. زر "إزالة البيانات التجريبية" ينقلها كلها لسلة المهملات.

## رابط العرض الدائم (WordPress Playground)
بعد رفع المستودع على GitHub (عام):

https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/wwwfadi412com-dev/bayt-kahraba/main/playground/blueprint.json

كل زائر يحصل على نسخة كاملة من المتجر مع البيانات التجريبية والصور خلال دقيقة تقريباً (ووكومرس + القالب + 26 منتجاً)، وتعديلاته لا تُحفظ — للعرض فقط. لوحة التحكم: `/wp-admin` باسم `admin` وكلمة مرور `password`.
بعد أي تعديل على القالب: `npm run build && npm run zip` ثم اعمل commit لملف `dist/bayt-kahraba.zip`، ثم `npm run pin` (يثبّت رابط الملف في الـ blueprint على هذا الـ commit) ثم commit و push. التثبيت على الـ commit ضروري لأن GitHub يخزّن الروابط العادية مؤقتاً ويتجاهل `?v=`.

## ما الذي يُدار من لوحة التحكم
| الشاشة | الاستخدام |
|---|---|
| المنتجات ← الماركات | شعار، بانر، لون، الوكالة، نص الكفالة + مدتها بالأشهر، مراكز الصيانة، أسئلة شائعة، دليل شراء مخصص |
| المنتجات ← التصنيفات | صورة، فئة الوزن للشحن (صغير/كبير، تُورّث للأبناء)، ملف الكلمات المفتاحية، مقدمة ودليل SEO مخصص |
| المنتج ← تبويب "الكهرباء والمواصفات" | الواط، الأمبير، التوافق مع الطاقة الشمسية، الموديل، السعة، الأبعاد، المميزات، أسئلة |
| المنتج ← عام | السعر المرجعي بالدولار (مخفي عن الزبون) |
| بيت الكهرباء ← التسعير ومزامنة المحل | سعر الصرف اليومي + التقريب (50 … 10,000) ← "تحديث جميع الأسعار فوراً" لكل المتجر/ماركة/تصنيف، معاينة قبل التطبيق، سجل، ورقة Excel/CSV للأسعار والمخزون |
| بيت الكهرباء ← التوصيل والشحن | مناطق التوصيل المجاني، رسوم ريف دمشق لكل منطقة، رسوم المحافظات (صغير/كبير)، شركات الشحن ومدد التوصيل |

## الميزات
- **الطلب عبر واتساب لكل منتج**: زر في البطاقة، زر كبير في صفحة المنتج، شريط ثابت على الموبايل، وأسئلة سريعة — كل رسالة تحمل اسم الجهاز والموديل والسعر والرابط. نص الرسائل قابل للتعديل بالفلتر `bk_product_whatsapp_message`.
- **فلتر وشارة الأمبير والطاقة الشمسية**: شارة على البطاقة، فلتر (طاقة شمسية/أمبير منخفض)، ومفتاح الأمبير في الواجهة.
- **فلاتر بسيطة قابلة للأرشفة**: روابط وGET عادية (الماركة، الترتيب، نوع الكهرباء) بدون JavaScript.
- **بحث فوري** بالمرادفات السورية (براد/ثلاجة، شاشة/تلفزيون…) مع اختصار `/` على الكمبيوتر.
- **صفحات الماركات وصفحات التقاطع** `/brand/{ماركة}/{قسم}/` مع معلومات الوكيل والكفالة.
- **SEO/GEO بدون إضافات**: عناوين ووصف وH1 ومقدمات وأدلة شراء مولّدة من بيانات حقيقية، Schema متكامل (Store، Product+Offer، CollectionPage، BreadcrumbList، FAQPage)، سايت ماب لصفحات التقاطع، و `/llms.txt`.
  إن كانت Yoast أو Rank Math مفعّلة، يترك القالب لها الوسوم الوصفية ويُبقي Schema التجارة والمسارات و llms.txt.
- **التسعير بالدولار ومزامنة سعر الصرف** لكل المتجر أو حسب الماركة/التصنيف.

## الأداء
CSS واحد (~10KB بعد gzip)، JS واحد مؤجل (~4KB بدون أي مكتبة)، خطوط IBM Plex Sans Arabic محلية مع preload، إزالة block-library/wc-blocks/emoji/oEmbed/jquery-migrate، تحويل تلقائي للصور إلى WebP، `fetchpriority=high` لصورة LCP، وتخزين مؤقت بمفاتيح مُرقّمة يُلغى تلقائياً عند أي تعديل.
للوصول إلى 98+: فعّل كاش صفحات (LiteSpeed Cache / WP Super Cache) + Redis Object Cache إن توفر. القالب متوافق بالكامل مع كاش الصفحات (لا سلة ولا جلسات على الواجهة).

## التطوير
```bash
npm install
npm run build      # الخطوط + CSS + JS
npm run dev:css    # مراقبة Tailwind
npm run lint:php   # فحص صياغة كل ملفات PHP
```
البنية والقواعد الهندسية في `CLAUDE.md`، والنقل من الاستضافة المجانية إلى الإنتاج في `docs/DEPLOYMENT.md`.
