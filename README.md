# بيت الكهرباء — قالب ووكومرس للأدوات الكهربائية والمنزلية في سوريا

قالب WordPress + WooCommerce مخصص بالكامل، عربي RTL، فائق السرعة (Tailwind + Alpine.js بدون jQuery في الواجهة)، مبني ليتوسع بلا حدود: أي ماركة أو تصنيف (أب ← ابن ← فرعي) تضيفه من لوحة التحكم يظهر تلقائياً في القائمة الضخمة، صفحات الماركات، صفحات التقاطع `/brand/{ماركة}/{قسم}/`، الفلاتر، السايت ماب، الـ Schema و `llms.txt` — بدون لمس أي سطر كود.

## الهوية البصرية: «فولت — ورقة المواصفات»
المتجر مصمم كورقة مواصفات هندسية أنيقة: الواط والأمبير هما اللغة البصرية للموقع.
- **الألوان:** ورقي دافئ `#F2EFE8`، حبر `#121212`، برتقالي كهربائي واحد للأفعال `#FF5B1F`، وأخضر مخصص للطاقة الشمسية فقط `#12A150`.
- **الخطوط (محلية بالكامل):** Alexandria للعناوين، IBM Plex Sans Arabic للنصوص، IBM Plex Mono لقراءات الواط والأمبير والموديلات.
- **عناصر مميزة:** حاسبة "كم أمبير عندك؟" في الواجهة (تعمل على منتجاتك الحقيقية)، بطاقة منتج بقراءات ومقياس استهلاك ملوّن، شريط سعر الصرف المتحرك، أقسام بشبكة غير متساوية، وسجلّ الوكلاء.
- **النموذج الأصلي للتصميم:** `design/concept-volt.html`. كل الألوان معرّفة في `tailwind.config.js` (الأسماء القديمة مربوطة بالألوان الجديدة).

## التشغيل خلال 5 دقائق
1. ارفع مجلد `bayt-kahraba` إلى `wp-content/themes/` (الملفات المبنية `assets/*/dist` موجودة — لا يحتاج الخادم Node).
2. فعّل **WooCommerce** ثم فعّل القالب.
3. الإعدادات ← الروابط الدائمة ← "اسم المقالة" ← حفظ.
4. **بيت الكهرباء ← تهيئة المتجر والبيانات التجريبية** ← "تهيئة المتجر" (أو `wp bk seed`).
5. **بيت الكهرباء ← الإعدادات العامة**: الاسم، الهاتف، واتساب، العنوان، صورة الواجهة.

> ⚠️ نصوص الكفالة ومراكز الصيانة وأرقام الموديلات والأسعار في البيانات التجريبية **قيم نموذجية** — راجعها مع كل وكيل (الحافظ، العربي، هنديكو، رامكو) قبل الإطلاق. زر "إزالة البيانات التجريبية" ينقلها كلها لسلة المهملات.

## رابط العرض الدائم (WordPress Playground)
بعد رفع المستودع على GitHub (عام):

https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/wwwfadi412com-dev/bayt-kahraba/main/playground/blueprint.json

كل زائر يحصل على نسخة كاملة من المتجر مع البيانات التجريبية خلال دقيقة تقريباً (ووكومرس + القالب + 26 منتجاً)، وتعديلاته لا تُحفظ — للعرض فقط. لوحة التحكم: `/wp-admin` باسم `admin` وكلمة مرور `password`.
بعد أي تعديل على القالب: `npm run build && npm run zip` ثم اعمل commit لملف `dist/bayt-kahraba.zip`، ثم `npm run pin` (يثبّت رابط الملف في الـ blueprint على هذا الـ commit) ثم commit و push. التثبيت على الـ commit ضروري لأن GitHub يخزّن الروابط العادية مؤقتاً ويتجاهل `?v=`.

## ما الذي يُدار من لوحة التحكم
| الشاشة | الاستخدام |
|---|---|
| المنتجات ← الماركات | شعار، بانر، لون، الوكالة، نص الكفالة + مدتها بالأشهر، مراكز الصيانة، أسئلة شائعة، دليل شراء مخصص |
| المنتجات ← التصنيفات | صورة، فئة الوزن للشحن (صغير/كبير، تُورّث للأبناء)، ملف الكلمات المفتاحية، مقدمة ودليل SEO مخصص |
| المنتج ← تبويب "الكهرباء والمواصفات" | الواط، الأمبير، التوافق مع الطاقة الشمسية، الموديل، السعة، الأبعاد، المميزات، أسئلة، فيديو المحل، باقة العرسان |
| المنتج ← عام | السعر المرجعي بالدولار (مخفي عن الزبون) |
| بيت الكهرباء ← التسعير ومزامنة المحل | سعر الصرف اليومي + التقريب (50 … 10,000) ← "تحديث جميع الأسعار فوراً" لكل المتجر/ماركة/تصنيف، معاينة قبل التطبيق، سجل، ورقة Excel/CSV للأسعار والمخزون |
| بيت الكهرباء ← التوصيل والشحن | مناطق التوصيل المجاني، رسوم ريف دمشق لكل منطقة، رسوم المحافظات (صغير/كبير)، شركات الشحن ومدد التوصيل |
| بيت الكهرباء ← حاسبة تجهيز العرسان | خطوات الحاسبة (مرتبطة بأي تصنيف)، نسبة خصم الباقة، الحد الأدنى للأجهزة |
| بيت الكهرباء ← سجل الكفالات | كل الكفالات الإلكترونية (تُنشأ تلقائياً عند اكتمال الطلب أو من صفحة التحقق) |
| ووكومرس ← الإعدادات ← الدفع | الدفع عند الاستلام (يظهر لدمشق وريفها فقط) + الحوالات المعتمدة (الهرم، الفؤاد، سيريتل كاش، شام كاش) |

## الميزات
- **فلتر وشارة الأمبير والطاقة الشمسية**: شارة خضراء على البطاقة والمنتج، فلتر فوري (بطارية/انفرتر/شمسي، اقتصادي، حتى 1/2/5 أمبير).
- **حاسبة تجهيز العرسان**: 3 باقات (اقتصادية / التوفير الذكي / فاخرة)، تبديل أي جهاز، مجموع وخصم فوري، إضافة الباقة كاملة للسلة أو طلبها بواتساب.
- **مقارن الموديلات**: حتى 4 منتجات، شريط عائم ونافذة مقارنة (السعر، الماركة، القسم، الكفالة، الواط، الأمبير، السعة، الأبعاد، التوفر) مع إبراز الأفضل.
- **الكفالة الإلكترونية**: الشورت كود `[bk_warranty]` — شروط كل وكيل + تسجيل/استعلام برقم الطلب والموبايل.
- **فيديو من أرض المحل**: فقاعة "ستوري" لا تُحمّل الفيديو إلا عند الضغط.
- **التوصيل الثلاثي**: مجاني (دمشق والريف القريب)، رمزي (الريف الأبعد حسب المنطقة)، المحافظات (حسب فئة الوزن). حاسبة توصيل في صفحة المنتج والسلة الجانبية.
- **صفحة دفع بـ 4 حقول**: الاسم، موبايل واتساب (تحقق `09xxxxxxxx`)، المحافظة + المنطقة، العنوان وعلامة مميزة.
- **واتساب**: طلب منتج/سلة/باقة/صفحة الدفع برسالة مفصلة (المنتجات، الموديل، الماركة، المنطقة، التوصيل، الإجمالي).
- **SEO/GEO بدون إضافات**: عناوين ووصف وH1 ومقدمات وأدلة شراء H2/H3 مولّدة من بيانات حقيقية (عدد الموديلات، نطاق الأسعار، الماركات)، مرادفات سورية (براد/ثلاجة، شاشة/تلفزيون…) في البحث والمحتوى، Schema متكامل (Store، Product+Offer+Shipping، CollectionPage+ItemList، BreadcrumbList، FAQPage)، سايت ماب لصفحات التقاطع، و `/llms.txt` + `/llms-full.txt`.
  إن كانت Yoast أو Rank Math مفعّلة، يترك القالب لها الوسوم الوصفية ويُبقي Schema التجارة والمسارات و llms.txt.

## الأداء
CSS واحد مضغوط (~66KB قبل gzip)، JS واحد مؤجل (~74KB يشمل Alpine)، خطوط IBM Plex Sans Arabic محلية مع preload، إزالة block-library/wc-blocks/emoji/oEmbed/jquery-migrate، سكربتات ووكومرس فقط في السلة/الدفع/الحساب والمنتجات المتغيرة، تحويل تلقائي للصور إلى WebP، `fetchpriority=high` لصورة LCP، وتخزين مؤقت بمفاتيح مُرقّمة يُلغى تلقائياً عند أي تعديل.
للوصول إلى 98+: فعّل كاش صفحات (LiteSpeed Cache / WP Super Cache) + Redis Object Cache إن توفر. القالب متوافق مع كاش الصفحات (السلة تُحمّل عبر Store API، والـ nonce يتجدد تلقائياً).

## التطوير
```bash
npm install
npm run build      # الخطوط + CSS + JS
npm run dev:css    # مراقبة Tailwind
npm run lint:php   # فحص صياغة كل ملفات PHP
```
البنية والقواعد الهندسية في `CLAUDE.md`، والنقل من الاستضافة المجانية إلى الإنتاج في `docs/DEPLOYMENT.md`.

## المتطلبات
WordPress 6.4+، WooCommerce 8.5+، PHP 8.1+. صفحة الدفع الكلاسيكية مطلوبة (التحويل تلقائي بزر واحد إن كانت Block).
